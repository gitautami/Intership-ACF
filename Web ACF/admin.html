Panduan Integrasi Google Spreadsheet & Dashboard

Formulir kemitraan dan relawan terhubung langsung dengan Google Apps Script Web App. Data yang diisi oleh calon mitra atau relawan otomatis masuk ke spreadsheet Anda secara terpisah pada sheet Mitra Program dan Relawan Eduhub.

🔗 URL Web App Google Apps Script Terpasang:

https://script.google.com/macros/s/AKfycbyBPKjNYHI1M3NifBOQJnH2Rjt_HUzxyZroYxLb2iPt7XMp72leWUjVtDACrqlxfadT/exec

Spreadsheet ID: 1W83sA-Tz-YrTe53Y4zuvV4ucdB198pQDR0gZn6_KfZU

💡 Fitur Unggulan Dashboard Ini:

  • Pemisahan Tab Jelas: Memisahkan calon Mitra Instansi/CSR dengan Relawan Individu secara otomatis.
  • Klik Cepat WhatsApp: Klik tombol Chat WhatsApp pada rincian data untuk langsung chat tanpa simpan nomor.
  • Manajemen Status: Mengubah status pendaftar (Menunggu, Sudah Dihubungi, Diterima, Arsip).
  • Export CSV: Klik tombol Export CSV di kanan atas untuk mengunduh berkas laporan excel kapan saja.
